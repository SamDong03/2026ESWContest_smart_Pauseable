# 학습 후 독립 재검산과 남은 오류

## 재검산

- 별도 검토에서 `predictions.csv`의 9개 평가 조합의 정확도, 균형정확도,
  정밀도, 재현율, F1, ROC-AUC, 혼동행렬, 경로 유형별 정답 수가
  `metrics.json`과 일치함을 확인했습니다.
- 라벨 있는 경로 총 4,112개에서 경로 ID, 그룹 ID, 정·역방향 정규화
  기하 지문의 분할 간 중복이 없었습니다. 모든 유사한 경로의 독립성을
  증명하는 검사는 아닙니다.
- 제외된 8개는 원본의 점 1개 경로 7개와 점 2개 경로 1개입니다.
- 내보낸 JSON 모델과 sklearn 점수는 1,520개 최종 평가 경로에서
  최대 절대오차 1.11e-16으로 일치했습니다.
- 재구성한 기존 RF와 실제 기존 모델
  `runs/20260911T112217637709Z/model.joblib`의 점수를 새 합성 경로
  1,000개에서 비교했으며 최대 절대오차는 2.22e-16이었습니다.
  해당 과거 `runs/` 폴더는 저장소 패키지에서 제외했으며, 이 문장은 당시 수행한 검증 기록입니다.
- 원본 `features.py`와 보존한 `legacy/features.py`의 SHA256이 일치합니다.

## 반드시 함께 설명해야 하는 한계

1. 기존에 틀렸던 SmartCare 017은 새 모델도 놓칩니다. 점수는 약
   0.4824에서 0.2768로 바뀌었습니다. 기존 20개 정확도는 여전히 95%입니다.
2. 이전 `weak_loop` 21개는 새 모델에서 모두 클래스 0입니다. 최고 점수는
   약 0.1862입니다. 이 곡선들은 정답이 정해지지 않은 탐색 사례이므로,
   클래스 1이 더 많이 나오는 것을 개선의 증거로 삼지 않았습니다.
3. 기존 사용자 파일 `sample_wandering_300.json`은 새 모델에서도
   점수 약 0.05825, 클래스 0입니다. 파일 이름은 정답 라벨이 아니며,
   이 경로가 실제 배회인지도 현재 자료만으로 확정할 수 없습니다.
4. 새 합성 1,000개 및 다른 구성의 합성 500개에서 100%를 얻었지만,
   이는 사전에 정한 생성 규칙의 반복/비반복 형태를 구분한 결과입니다.
   실제 환자 배회 정확도 100%라는 뜻은 아닙니다.
5. 같은 개발 분할에서 학습한 9개 특징 기준 모델은 기존 20개에서 100%를
   기록했습니다. 선택 모델이 모든 평가에 걸쳐 우월한 것은 아닙니다.

선택 모델은 새로운 연구 후보로 전달합니다. 기존 모델이나 현재 Pi5 앱의
실사용 모델을 자동으로 교체하지 않습니다. 점수·유형별 실패·실측 검증
결과를 함께 검토한 뒤 향후 배포 모델을 결정해야 합니다.

## 후속 민감도 시험

`ROBUSTNESS.md`와 `robustness.json`은 모델을 동결한 뒤 수행한 별도
합성 변형 시험입니다. 같은 기본 경로를 다시 변형한 짝지은 평가이므로
추가 독립 표본으로 합산하지 않습니다. 이 점수를 보고 재학습하거나
판정 기준값을 다시 조정하지 않습니다.
