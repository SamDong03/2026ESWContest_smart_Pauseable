## 분석 구성

센서 대상의 이동을 구간으로 묶고 경로 형태와 개인 과거 분포의 변화를 따로 계산합니다. 이후 연속 구간·누적 시간과 관측 품질을 확인해 검토 후보를 만듭니다.

| 구성 | 현재 처리 |
| --- | --- |
| 경로 형태 | v2 JSON Random Forest, 36개 특징. 기존 v1 사용은 명시적으로 선택 |
| 개인 이력 | 기존 9개 특징 규격을 유지해 과거 분포와 비교 |
| 지속성 | 형태·개인 증거를 분리해 연속 구간과 누적 시간 확인 |
| 스트림 상태 | 센서·출처·대상별 분리, 세션 전환 시 초기화 |
| 모델 검사 | 노드·인덱스·순환·유한수·크기 제한 검사 |
| 출력 | JSON 결과와 선택적 stderr 집계, 모델·정책·특징 버전 기록 |

## 후보 생성과 해제

현재 시험 정책은 다음과 같습니다.

| 항목 | 조건 |
| --- | --- |
| 지속성 | 높은 증거가 최소 3개 연속 구간이며 총 90초 이상 |
| RF 후보 시작 | 선택한 모델에 저장된 기준. 현재 모델은 0.66 |
| RF 후보 해제 | 시작 기준에서 0.10을 뺀 값 미만 |
| 개인 변화 시작 | 개인 비교 분포의 95백분위 이상 |
| 개인 변화 해제 | 개인 비교 분포의 90백분위 미만 |

후보 생성 전 경계 근처 점수는 높은 증거로 누적하지 않습니다. 후보를 만든 뒤에는 더 낮은 해제 기준을 적용해 점수 경계에서 상태가 반복 전환되는 것을 줄입니다. 위 숫자는 저장된 소프트웨어 정책이며, 실측 라벨에 대한 탐지 성능은 별도로 평가합니다.

## 관측 품질과 상태 처리

- 단절·저품질·모델 변경 시 누적 증거를 초기화합니다. 겹치거나 역순인 같은 스트림 구간은 누적하지 않습니다.
- 개인 기준선·대상자 지정이 바뀌면 개인 증거만 초기화하고 경로 형태 증거는 유지합니다.
- 개인 이력이 없으면 형태를 검토할 수 있지만 개인 분석은 `unavailable`입니다.
- UTC 미동기 상태에서는 상대시간 형태 분석을 허용하고 경고를 기록합니다. 개인 기록 저장은 보류합니다.
- 시계 회귀 패킷은 uptime을 확인한 뒤 seq를 갱신합니다.
- 입력·모델·정책·개인 기준선 버전이 다른 재실행에 이전 상태를 재사용하지 않습니다.

입력이 끊기면 새 구간 생성도 멈출 수 있습니다. 실시간 연결에서는 수신기의 stale/silent 상태를 함께 확인하고, 저장된 과거 후보를 현재 상태처럼 계속 표시하지 않습니다.

## 결과 상태

| 상태 | 의미 |
| --- | --- |
| `shape_review_candidate` | 반복 경로 형태 증거가 지속됨 |
| `personal_change_candidate` | 개인 과거 분포와 다른 형태가 지속됨 |
| `combined_review_candidate` | 두 증거가 모두 지속됨 |
| `partial_evidence` | 개인 비교 자료 없이 형태 증거를 확인 중 |
| `no_current_rule_flag` | 이번 정책에서 후보 조건 미충족 |
| `insufficient_evidence` | 관측 부족으로 판단 보류 |

결과에는 RF 점수·모델 해시·특징 버전·개인 기준선 버전·누적 시간과 근거가 남습니다. 개인에게 드문 경로가 아니라는 이유만으로 지속되는 반복 형태 후보를 차단하지 않습니다.

## 모델과 DB 호환

RF의 36개 특징을 기존 9개 특징 개인 DB에 섞지 않습니다. 다른 모델·정책 버전으로 같은 입력을 다시 평가할 때는 별도 DB를 사용합니다. 기본값 0.5를 임의로 적용하는 대신 선택 모델의 저장된 임계값을 사용합니다.

## 검증 상태

`synthetic_shape_class`는 합성 경로 형태의 분류입니다. 저장된 연구 평가는 `simulated_only`이며 연구 모델의 `alert=false`를 유지합니다. 시연 Publisher와 실제 장치의 설정은 이 연구 결과와 구분해 확인합니다.

실측 LD6004의 좌표 단위·추적 품질·구간 길이, 목적 있는 왕복·운동을 포함한 확인 라벨, 오탐·미탐·판정 시각은 추가 검증 대상입니다. Python 분석과 Pi 5 C++ 이식의 수치 일치도 별도 확인 항목입니다.
