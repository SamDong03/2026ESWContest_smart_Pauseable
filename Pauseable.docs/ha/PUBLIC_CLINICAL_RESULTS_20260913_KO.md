# 공개 임상·생활센서 데이터 추가 결과

검증일: 2026-09-13. 기존 가전 모델과 분리된 PC 연구 실행 결과다.

## 한눈에 보기

| 자료 | 실제로 읽은 범위 | 실제 학습·평가 | 의미 |
|---|---|---|---|
| TIHM | 56명 활동 1,030,559행, 건강 사건 608행 | 26명별 IF+AE, 미래 평가 319개 관찰일 | 치매 환자의 개인 routine 변화와 기록된 사건 비교 |
| CASAS Cognitive | 진단 400항목, 사용 가능 센서 세션 346개 | 기준군 학습 70명, 임계값 보정 24명, 평가 98명 | 참가자를 분리한 인지평가 세션 비교 |
| MIRATAR | 50가구 CSV 400개, 원본 9,897,160행 | 모션/문 특징으로 48가구별 IF+AE, 평가 1,598일 | 실제 가정 센서 입력·routine 변동 시험. 치매 정답 없음 |

자료 설명만 참고한 것이 아니라 ZIP 원본을 다운로드하고 실제 데이터로 가중치를 학습했다.
단, 그 가중치는 연구 폴더에만 저장했다. Pi 운영 baseline/Autoencoder 가중치에는 넣지 않았다.
UK-DALE/REFIT은 그대로 전력 분석용 보조 데이터다. 치매 임상 정답으로 바꾸지 않았다.

## 결과를 어떻게 읽어야 하나

### TIHM: 사건일이 너무 적고 정상 정답은 없다

- 활동 CSV에 기록이 있는 날은 2,722개 사람-날이다. 소개의 전체 수집 2,803일과 동일하지 않다.
- 데이터 길이와 사건일 제외 조건을 만족한 26명만 학습했다. 나머지 30명은 제외 이유를 JSON에 기록했다.
- Agitation 원본 라벨은 135행이며 사람/날짜별로 중복을 합치면 115개 사건일이다.
- 이 중 이번 미래 평가 구간에 센서 점수가 있는 사건일은 6일, IF와 AE 모두 같은 1일에 경보를 냈다.
- 이는 1/6 같은 날짜 겹침이다. 전체 사건 135건 중 1건을 예측했다는 뜻도, 치매 진단 정확도도 아니다.
- 다른 건강 사건도 종류별 결과를 저장했다. 정상 정답이 없어 precision/오탐률/ROC-AUC는 계산하지 않았다.

### CASAS: 순위 구분 신호는 있지만 놓치는 비율이 높다

평가 98명 = 별도 기준군 24명 + 치매 20명 + MCI 54명.
아래는 calibration 기준군 점수의 95백분위로 임계값을 고정했을 때의 결과다.

| 비교 | IF ROC-AUC | AE ROC-AUC | IF 또는 AE 경보를 받은 양성 참가자 |
|---|---:|---:|---:|
| 치매 대 기준군 | 0.642 | 0.731 | 6/20 (30.0%) |
| MCI 대 기준군 | 0.473 | 0.573 | 6/54 (11.1%) |

IF 또는 AE 결합에서 기준군 24명 중 3명에도 경보가 있었다.
AUC는 순위 구분 정도이지 정확도가 아니다. 높은 AUC만 보고 놓치는 비율을 숨기면 안 된다.
이 결과만으로 IF보다 AE가 일반적으로 우수하다거나 실제 가정의 치매 조기탐지가 가능하다고 결론 내릴 수 없다.
원논문의 코호트/특징/평가 프로토콜 재현도 아니다.

400항목 중 검사 없음 38개, 센서 없음 11개, 파싱 불가 4개, 시계 역행 1개를 제외했다.
346개 세션 중 젊은 성인·기타 질환·위험/미상 등을 연구 기준군과 합치지 않아 학습/보정/평가 대상은 192명이다.
검사 도움말, 미완료, 제외 편향이 남아 있다.

### MIRATAR: 임상 정답 없는 참고 실험

- 모션 200파일 + 문 50파일로 특징을 만들고, 온도 150파일은 품질 목록만 작성했다.
- 시각이 없는 9행은 날짜를 만들어 넣지 않고 제외했다. 유효 CSV 행 수는 9,897,151행이다.
- 다섯 센서 기록이 모두 있는 사람-날 특징 8,172개를 얻었다. M07/M44는 30개 관찰일 미만이라 학습하지 않았다.
- IF 또는 AE 경보 비율은 평가일의 16.3%였다. 정답이 없으므로 이것은 정확도나 오탐률이 아니다.
- 전력·가전 작동 사이클·치매 진단을 이 자료에서 만들어내지 않았다. 외부 제공 모델을 실행하지 않았다.

## 검증과 남은 문제

- 기존 58개 + 신규 15개 = 테스트 73개 통과.
- 자체 학습한 IF/AE 묶음 75개를 저장 후 다시 읽어 2,015개 평가 점수를 재현했다.
- 학습/보정/평가 식별자 중복 없음, 임계값은 보정 데이터로만 계산됨, 운영 형식과 분리됨을 검사했다.
- 75개 AE 중 53개에서 400회 안에 수렴하지 않았다는 최적화 경고가 있다(TIHM 26, CASAS 1, MIRATAR 26).
  점수 계산은 수행했지만 충분히 학습되었다고 볼 수 없다. 경고를 숨기거나 운영에 승격하지 않았다.
- 다음 개선은 학습/보정 구간 안에서 최적화와 특징 설계를 개선하고, 아직 보지 않은 독립 평가 자료로 검증하는 것이다.
  이번 평가 결과를 보고 임계값을 조절한 뒤 같은 자료를 새 성능처럼 보고하면 안 된다.
- 일별 집계는 가전 반복 조작 순서나 미완료 동작을 충분히 표현하지 못한다. 기존 HA의 1분/10분 행동 규칙을 대체하지 않는다.

## 아직 확보하지 못한 핵심 자료

엑셀의 #31 Personalized IADL 논문은 정상군/초기 치매군의 실제 가전·생활 센서를 다룬다.
하지만 원자료는 저자 요청 방식이므로 이번 작업에 넣지 못했다. 치매 환자의 가전별 원자료까지 확보됐다고 해석하면 안 된다.

MIRATAR 이외의 후보도 확인했다. MAISON-LLF는 최신 공개판 기준 골절 회복 고령자 자료이고 이미 보간된 특징이어서 이번 치매 가전 평가에는 넣지 않았다.
KFall/영상 자료는 입력 종류가 다르고, 통영 통계는 개인 시계열이 아니며, DPUK/Minder는 별도 승인 경로가 필요하다.

## 변경 및 파일 위치

기존 프로젝트에는 새 코드 4개, 테스트 1개, 설명서 2개만 추가한다.
공개 원본/연구 모델은 이 작업의 `outputs/ha_clinical_data_20260913/` 아래에 보관한다.
Pi에는 접속하거나 모델을 배포하지 않았다. 원래 30일 개인 데이터 수집 -> 학습 -> 검증 후 사용 구조는 유지한다.

- `downloads/`: 원본 ZIP 3개, Zenodo 기록 JSON, URL/MD5/SHA-256/이용 조건.
- `experiments_final/`: 채택한 최종 연구 실행. 각 데이터의 report/feature/score/model/split.
- `experiments_v1/`: 개발 중 첫 실행 기록. MIRATAR 누락 시각 때문에 중단됐으며 최종 결과로 쓰지 않음.
- `verification.json`: 저장한 75개 모델의 점수 재현 검증.
- `actions.jsonl`, `*.log`, `WORK_LOG_KO.md`: 실행 명령·성공/실패·수정 과정.
