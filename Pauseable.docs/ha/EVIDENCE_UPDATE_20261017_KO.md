# 추가 문헌과 연구 시나리오

작성일: 2026-10-17. 목적은 제출용 연구 근거와 소프트웨어 시험 보강이다.
환자 실측 파일을 새로 확보하거나 임상 반복 횟수를 정한 작업이 아니다.

기존 9개 근거는 10월 5일 문서를 따른다. 새 registry는 12개 근거와 16종 시나리오를 연결한다.
세탁기 전원 반복에는 직접적인 치매 환자 논문 근거를 확보하지 못했다.
일반적인 과제 재확인을 시연 신호에 적용한 공학적 유추라고 명시했다.

## 추가 시험 5종

| 시나리오 | 목적 |
| --- | --- |
| fridge_distributed_rechecks | 짧은 폭증 없이 2시간 동안 분산된 확인을 10분/30분/1시간 특징이 어떻게 보는지 비교 |
| normal_slow_meal | 과제 시간이 길다는 이유만으로 반복행동이라고 해석하는 문제 확인 |
| washer_power_recheck | 시연의 세탁기 전원 반복 어댑터가 기존 특징/모델에서 어떻게 점수화되는지 확인 |
| normal_washer_setup | 위 가설과 완전히 같은 전원 로그에 정상 준비라는 설명을 붙여, 의도를 센서만으로 구분할 수 없는 한계 확인 |
| normal_washer_full_cycle | 한 번 시작하고 자동 완료되는 동작이 여러 번 수동 재시작한 것으로 계산되지 않는지 확인 |

12분 간격, 70분 세탁, 5~15초 전원 켜짐 등은 모두 공학적 시험값이다.
각 논문에서 추정한 환자 분포나 임상 판정 기준이 아니다.
세탁기 power→operation 변환은 실제 드럼 작동을 측정한 것과 다르다.

## 데이터와 모델에 실제로 반영된 범위

- 연구 이미지에는 출처 registry, 생성기, 테스트와 실행 코드를 넣었다.
- 시나리오는 학습 이후의 별도 미래 시험 입력으로 생성한다. 증상 가설을 정상 라벨로 학습시키지 않는다.
- IF/AE 연구용 학습은 기존 정상 가정 합성 한 달을 사용한다. baseline 수치와 운영 개인 모델을 바꾸지 않았다.
- 상태 지속시간은 각 사례의 observation_summary.json에 별도 기록한다. 기존 54개 모델 특징에 새 열을 넣지 않았다.
- MINDER ZIP은 기존 선택 입력을 유지한다. 사용하면 fit 날짜의 시간대 집계만 참고한다. 공개 환자 원본을 Docker/Git에 복제하지 않는다.
- UK-DALE/REFIT의 정상 전력 자료는 가전 신호 연구용이다. 치매 반복행동 정답으로 바꾸지 않는다.

같은 로그에 정상 설명과 반복 가설이 모두 가능하다는 시험은 실패를 숨기기 위한 예외가 아니다.
모델 성능과 관찰 가능 범위를 나누어 보고하기 위한 대조군이다.
